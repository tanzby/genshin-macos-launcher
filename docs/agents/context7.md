# Current external documentation

For current library, framework, SDK, API, CLI, or cloud-service behavior, use Context7 CLI: `npx ctx7@latest library <official-name> <specific-question>`, then `npx ctx7@latest docs /org/project <full-question>`. A user-supplied `/org/project` ID skips lookup; keep the request to three commands. Skip Context7 for refactoring, standalone scripts, business-logic debugging, code review, and general programming. On quota errors, stop and suggest login or `CONTEXT7_API_KEY`; on DNS/network errors, retry outside the default sandbox.
